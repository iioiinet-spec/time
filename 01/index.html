소질·적성검사는 용어를 외웠는지 묻지 않습니다. 어떤 장치가 무슨 일을 하는지 역할로 구분할 수 있는지를 묻습니다. 2023학년도 기출이 정확히 그랬습니다. 영문 지문이 장비의 기능 세 가지를 설명하고, 그 장비의 이름을 고르게 했습니다. 지문에 라우터라는 단어는 한 번도 나오지 않았습니다.

그래서 이 책은 각 장치마다 무엇을 보고 판단하는가를 중심에 둡니다. 표를 외우지 말고, 표의 "판단 기준" 칸만 설명할 수 있으면 됩니다.

Chapter 01컴퓨팅 시스템의 구성

컴퓨터는 하나의 덩어리가 아니라 역할이 다른 부품들이 협력하는 시스템입니다. 이 장에서는 그 역할 분담을 봅니다.

1.1 하드웨어와 소프트웨어

하드웨어 hardware는 눈에 보이고 손에 잡히는 물리적 장치입니다. 소프트웨어 software는 하드웨어에게 무엇을 할지 지시하는 명령의 모음입니다. 둘 중 하나만으로는 아무 일도 일어나지 않습니다. 악보 없는 악기, 악기 없는 악보와 같습니다.

하드웨어는 하는 일에 따라 다섯 갈래로 나눕니다.

표 1-1 하드웨어의 다섯 가지 역할
구분하는 일예
제어장치명령을 해석하고 다른 장치에 신호를 보냄CPU 안에 포함
연산장치계산과 비교·판단을 수행CPU 안에 포함

터치스크린은 입력장치인가 출력장치인가? 둘 다입니다. 화면을 보여 주는 기능은 출력, 손가락 위치를 받아들이는 기능은 입력입니다. 복합기도 마찬가지로 스캔은 입력, 인쇄는 출력입니다. 장치의 이름이 아니라 정보가 어느 방향으로 흐르는가로 판단하십시오.

1.2 중앙처리장치

중앙처리장치 CPU, Central Processing Unit는 컴퓨터의 두뇌입니다. 사람이 지시한 명령을 실제로 수행하는 곳이고, 세 부분으로 이루어집니다.

  • 제어장치 — 명령어를 해석해 각 장치에 지시를 내립니다. 지휘자 역할입니다.
  • 연산장치 — 더하기·빼기 같은 산술 연산과 크다·같다 같은 논리 연산을 수행합니다.
  • 레지스터 — CPU 안에 있는 아주 작고 아주 빠른 임시 저장 공간입니다. 지금 당장 쓰는 값만 잠깐 올려 둡니다.

명령어가 처리되는 네 단계

CPU는 전원이 켜져 있는 동안 다음 네 단계를 쉬지 않고 반복합니다. 이 반복을 명령어 사이클이라고 부릅니다.

  1. 인출 fetch — 주기억장치에서 다음 명령어를 가져옵니다.
  2. 해석 decode — 제어장치가 그 명령이 무엇을 하라는 것인지 풀이합니다.
  3. 실행 execute — 연산장치가 실제로 계산하거나 자료를 옮깁니다.
  4. 저장 store — 결과를 레지스터나 주기억장치에 씁니다.

CPU의 성능을 말할 때 쓰는 클럭은 이 사이클을 1초에 몇 번 반복하는지를 나타냅니다. 3.0 GHz라면 1초에 30억 번입니다. 코어는 이 일을 동시에 할 수 있는 CPU 안의 일꾼 수입니다. 4코어는 네 가지 작업을 나란히 처리할 수 있다는 뜻입니다.

1.3 기억장치의 계층

기억장치는 하나가 아니라 여러 층으로 쌓여 있습니다. 빠른 것은 비싸서 조금밖에 못 쓰고, 싼 것은 느리지만 많이 쓸 수 있기 때문입니다. 위로 갈수록 빠르고 비싸고 작으며, 아래로 갈수록 느리고 싸고 큽니다.

RAM은 읽고 쓰기가 모두 되지만 전원이 끊기면 내용이 사라집니다. 작업하던 문서를 저장하지 않고 컴퓨터를 끄면 날아가는 이유입니다. ROM은 주로 읽기용이고 전원이 꺼져도 내용이 남습니다. 컴퓨터를 켤 때 가장 먼저 실행되는 시동 프로그램이 여기에 들어 있습니다.

1.4 버스 — 부품 사이의 통로

부품들이 서로 자료를 주고받으려면 길이 필요합니다. 이 길을 버스 bus라고 합니다. 자료가 오가는 데이터 버스, 어느 위치인지 알리는 주소 버스, 무엇을 하라는지 알리는 제어 버스로 나뉩니다. 버스의 폭이 넓을수록 한 번에 많은 자료를 옮길 수 있습니다.

확인 문제

  1. 전원을 끄면 내용이 사라지는 기억장치는 무엇이며, 그 성질을 뭐라고 부르는가?
  2. CPU의 명령어 처리 네 단계를 순서대로 쓰시오.
  3. "속도는 가장 빠르지만 용량이 가장 작고, CPU 내부에 있다." 어느 기억장치인가?
  4. 스캐너와 프린터가 한 몸에 들어 있는 복합기는 입력장치인가 출력장치인가? 이유와 함께 답하시오.

Chapter 02소프트웨어와 운영체제

같은 컴퓨터가 게임기도 되고 계산기도 되는 이유는 소프트웨어가 바뀌기 때문입니다. 그 소프트웨어들을 관리하는 소프트웨어가 운영체제입니다.

2.1 시스템 소프트웨어와 응용 소프트웨어

소프트웨어는 누구를 위해 일하느냐로 나뉩니다.

  • 시스템 소프트웨어 — 하드웨어를 돌보고 다른 소프트웨어가 일할 바탕을 만듭니다. 운영체제, 장치 드라이버, 컴파일러가 여기 속합니다. 사용자를 직접 상대하기보다 컴퓨터 자신을 돌봅니다.
  • 응용 소프트웨어 — 사용자가 하고 싶은 일을 처리합니다. 웹 브라우저, 문서 편집기, 게임, 메신저가 여기 속합니다. 사람의 목적을 위해 존재합니다.

2.2 운영체제가 하는 다섯 가지 일

운영체제 OS, Operating System는 하드웨어라는 자원을 여러 프로그램이 다투지 않고 나눠 쓰도록 중재합니다. 윈도우, macOS, 리눅스, 안드로이드, iOS가 모두 운영체제입니다.

  2. 프린터를 새로 연결했을 때 설치하는 소프트웨어의 이름과 분류를 쓰시오.
  3. "시스템 소프트웨어와 응용 소프트웨어를 가르는 기준"을 한 문장으로 쓰시오.

Chapter 03네트워크의 기초

네트워크는 컴퓨터를 연결해 자료를 주고받게 만든 구조입니다. 4장과 5장을 이해하려면 이 장의 용어가 먼저 서 있어야 합니다.

3.1 네트워크의 범위

  • LAN Local Area Network — 집, 교실, 사무실처럼 가까운 범위를 묶은 네트워크입니다. 보통 한 기관이 직접 관리합니다.
  • WAN Wide Area Network — 도시와 국가를 넘어 멀리 떨어진 네트워크를 묶습니다. 통신사가 관리합니다.
  • 인터넷 — 전 세계의 수많은 네트워크가 서로 연결된, 네트워크들의 네트워크입니다.

집 안의 기기들이 모여 있는 범위가 LAN이고, 그 LAN을 바깥 인터넷으로 이어 주는 자리에 있는 장치가 4장에서 다룰 라우터입니다. 이 구조를 먼저 그려 두면 장비 구분이 쉬워집니다.

3.3 패킷 — 자료를 쪼개서 보내는 이유

큰 파일을 통째로 한 번에 보내면 그 파일이 전송되는 동안 다른 사람은 선로를 쓰지 못합니다. 그래서 자료를 일정한 크기로 잘라 보냅니다. 이 조각을 패킷 packet이라고 합니다.

패킷은 내용물만 들고 가지 않습니다. 겉면에 보내는 주소, 받는 주소, 몇 번째 조각인지를 붙입니다. 덕분에 조각들이 서로 다른 길로 가도, 도착 순서가 뒤바뀌어도, 받는 쪽에서 번호를 보고 원래대로 맞출 수 있습니다. 중간에 잃어버린 조각이 있으면 그 조각만 다시 요청하면 됩니다.

기억해 둘 비유

두꺼운 책 한 권을 우편으로 보낸다고 합시다. 통째로 보내면 상자가 커서 느리고, 중간에 사고가 나면 전부 다시 보내야 합니다. 열 쪽씩 나눠 번호를 적은 봉투에 담아 보내면, 길이 막힌 봉투는 다른 길로 돌아갈 수 있고 하나가 분실돼도 그것만 다시 보내면 됩니다. 이것이 패킷 교환 방식입니다.

3.4 프로토콜과 계층

프로토콜 protocol은 서로 다른 기기가 통신하기 위해 미리 약속한 규칙입니다. 언어가 다른 두 사람이 대화하려면 공통의 언어가 필요한 것과 같습니다.

인터넷은 이 약속을 한 덩어리로 만들지 않고 네 개의 층으로 나눠 두었습니다. 각 층이 자기 일만 책임지면 되므로, 한 층을 새 기술로 바꿔도 나머지를 다시 만들지 않아도 됩니다.

Chapter 04네트워크 장비

2023학년도 소질·적성검사가 출제된 바로 그 구간입니다. 이름이 아니라 역할로 외우십시오.

4.1 장비들이 놓인 자리

집에서 인터넷을 쓸 때 신호가 지나는 길을 그리면 각 장비의 자리가 분명해집니다.

4.2 장비별 역할

허브

여러 기기를 하나로 모아 주는 가장 단순한 장비입니다. 한 포트로 들어온 신호를 나머지 모든 포트로 그대로 뿌립니다. 받는 사람이 누구인지 보지 않습니다. 그래서 연결된 기기가 많아지면 불필요한 신호가 넘쳐 충돌이 생기고 느려집니다.

스위치

허브와 생김새는 비슷하지만 똑똑합니다. 각 포트에 어떤 기기가 붙어 있는지 MAC 주소로 기억해 두었다가, 받는 기기가 붙은 포트로만 보냅니다. 나머지 포트는 조용합니다. 같은 네트워크 안에서 기기들을 효율적으로 연결하는 장비입니다.

라우터

서로 다른 네트워크를 이어 주는 장비입니다. 패킷에 적힌 목적지 IP 주소를 보고 어느 길로 보낼지 결정합니다. 집 안 네트워크와 바깥 인터넷의 경계에 서서 교통을 정리하는 역할입니다. 길이 여러 개면 더 나은 길을 고릅니다.

공유기

가정에서 쓰는 이른바 와이파이 공유기는 하나의 장비 안에 라우터 + 스위치 + 무선 접속점 + 주소 할당 기능이 모두 들어 있는 통합 기기입니다. 그래서 공유기 하나로 여러 기기가 하나의 인터넷 회선을 나눠 쓸 수 있습니다.

모뎀과 액세스 포인트

모뎀은 통신사가 보내는 신호와 컴퓨터가 쓰는 디지털 신호를 서로 변환하는 장비입니다. 액세스 포인트 AP는 유선 네트워크에 무선 기기가 접속할 수 있게 해 주는 출입구입니다.

영문 지문은 어떤 장비를 설명하면서 세 가지 기능을 들었습니다. 첫째 하나의 인터넷 회선으로 여러 기기가 동시에 접속하게 해 준다. 둘째 네트워크 안의 기기에 사설 IP를 나눠 주고, 사설 주소와 공인 주소를 서로 바꿔 준다. 셋째 패킷을 목적지 IP 주소로 전달한다.

보기에는 허브·LAN·라우터·암호화·프록시 서버가 있었고, 정답은 라우터였습니다. 판단 지점은 명확합니다. IP 주소를 다루고, 서로 다른 네트워크 사이에 선다는 두 가지가 동시에 나오면 라우터입니다. 허브와 LAN은 한 네트워크 안의 개념이라 둘째·셋째를 설명할 수 없습니다.

자주 틀리는 지점
  • 허브와 스위치는 포트가 여러 개라는 점만 같습니다. 가르는 기준은 "받는 사람을 보는가"입니다.
  • 스위치와 라우터는 둘 다 전달을 하지만, 스위치는 같은 네트워크 안에서 MAC 주소로, 라우터는 네트워크를 넘어 IP 주소로 전달합니다.
  • 모뎀과 공유기를 섞지 마십시오. 모뎀은 신호를 변환할 뿐 주소를 나눠 주지 않습니다. 요즘은 둘이 한 통에 들어 있는 제품이 많아 더 헷갈립니다.

Chapter 05IP 주소와 이름

네트워크에서 자료가 길을 찾아가려면 주소가 있어야 합니다. 그리고 사람이 외우기 위해서는 이름이 필요합니다.

5.1 IP 주소의 구조

IP 주소는 네트워크에 연결된 기기를 구별하는 번호입니다. 현재 널리 쓰이는 IPv4는 32비트로 이루어지고, 8비트씩 네 묶음으로 끊어 점으로 구분해 적습니다. 8비트는 0부터 255까지 나타낼 수 있으므로 각 칸의 값은 0~255 범위입니다.

192 . 168 . 0 . 15

32비트로 만들 수 있는 주소는 232, 약 43억 개입니다. 인터넷에 연결되는 기기가 늘면서 이 수가 부족해졌고, 그래서 128비트를 쓰는 IPv6가 등장했습니다. 자릿수가 네 배가 아니라 비트가 네 배이므로 주소의 개수는 비교할 수 없이 많아집니다.

5.2 공인 IP와 사설 IP

주소가 부족한 문제를 당장 푼 방법이 주소를 안과 밖으로 나누는 것이었습니다.

  • 공인 IP — 인터넷 전체에서 유일한 주소입니다. 통신사가 배정하며, 보통 집에 하나가 주어집니다.
  • 사설 IP — 집이나 학교 내부에서만 쓰는 주소입니다. 다른 집과 같은 주소를 써도 상관없습니다. 바깥에서는 보이지 않습니다.

그래서 집 안의 스마트폰·노트북·TV가 각각 사설 IP를 받아 쓰고, 바깥으로 나갈 때는 공유기가 가진 하나의 공인 IP로 바꿔서 나갑니다. 이 변환을 NAT Network Address Translation라고 합니다. 들어올 때는 반대로 바꿔 원래 기기에 돌려줍니다.

사설 IP를 기기마다 사람이 일일이 설정하면 번거롭습니다. 그래서 공유기가 접속한 기기에 주소를 자동으로 나눠 줍니다. 이 기능이 DHCP입니다.

아파트 비유

아파트 동 전체에 주어진 도로명 주소가 공인 IP, 그 안의 101호·102호가 사설 IP입니다. 택배 기사는 동까지만 오고, 경비실이 호수를 보고 각 집에 전달합니다. 이 경비실 역할이 NAT이고, 빈 호수를 새 입주자에게 배정해 주는 일이 DHCP입니다.

5.3 도메인과 DNS

숫자 주소는 기계에게 편하지만 사람이 외우기 어렵습니다. 그래서 도메인 이름이라는 문자 주소를 따로 씁니다. 사람이 도메인을 입력하면, 그에 해당하는 IP 주소를 찾아 주는 체계가 DNS Domain Name System입니다. 전화번호부에서 이름을 보고 번호를 찾는 것과 같습니다.

5.4 포트 — 같은 주소 안의 창구 번호

한 서버 컴퓨터는 웹도 제공하고 메일도 제공할 수 있습니다. IP 주소만으로는 어느 서비스를 원하는지 알 수 없으므로, 서비스마다 번호를 붙입니다. 이것이 포트 번호입니다. 웹은 80, 보안이 적용된 웹은 443을 씁니다. IP 주소가 건물 주소라면 포트는 그 건물의 창구 번호입니다.

Appendix B한 장 요약과 자기 점검표

시험 전날에는 이 두 쪽만 보십시오.

꼭 기억할 것

  • 하드웨어 분류는 장치 이름이 아니라 정보가 흐르는 방향으로 판단한다.
  • CPU 처리: 인출 → 해석 → 실행 → 저장.
  • 기억장치 계층: 레지스터 > 캐시 > 주기억 > 보조기억. 위일수록 빠르고 작고 비싸다.
  • RAM은 휘발성, ROM과 보조기억장치는 비휘발성.
  • 소프트웨어 분류: 컴퓨터 자신을 돌보면 시스템, 사용자 목적을 수행하면 응용.
  • 운영체제 5기능: 프로세스·기억장치·파일·주변장치·사용자 인터페이스 관리.
  • 패킷: 쪼개면 선로를 나눠 쓸 수 있고, 잃어버린 조각만 다시 보내면 된다.
  • TCP/IP 4계층: 응용 → 전송 → 인터넷 → 네트워크 접근. 경로 결정은 인터넷 계층의 IP.
  • 허브는 모두에게, 스위치는 MAC 주소로 해당 포트에만, 라우터는 IP 주소로 다른 네트워크에.
  • 공유기 = 라우터 + 스위치 + AP + DHCP + NAT.
  • IPv4는 32비트, 각 칸 0~255, 약 43억 개. 부족해서 IPv6(128비트)가 나왔다.
  • NAT는 사설↔공인 주소 변환, DHCP는 주소 자동 배정, DNS는 이름→주소 조회.
  • 접속 순서: 입력 → DNS 조회 → 연결 → 요청 → 응답 → 패킷 재조립 → 화면 표시.
