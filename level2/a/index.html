3. 귀류법 — 결론을 부정해 모순을 끌어내기

귀류법의 구조
명제 “P이면 Q이다”를 증명할 때
① 가정 — P가 참이고 Q가 거짓이라고 하자.
② 전개 — 이 가정에서 논리적으로 따라오는 것들을 끌어낸다.
③ 모순 — 이미 참인 사실이나 가정 자체와 어긋나는 결과가 나온다.
④ 결론 — 가정이 틀렸으므로 Q는 참이다.

주제 03의 기사·건달 퍼즐에서 “A를 기사라고 가정했더니 모순”이라며 A가 건달임을 알아낸 것이 바로 귀류법입니다. 이제 이것을 수의 세계에 씁니다.

귀류법이 좋은 때
“~가 아니다”, “불가능하다”, “무한히 많다”처럼 직접 보이기 어려운 것을 증명할 때 씁니다. 부정하면 “유한하다”, “가능하다”처럼 손에 잡히는 대상이 생기기 때문입니다.
자주 하는 실수
결론만 부정해야 하는데 가정까지 부정하거나, 모순을 찾지 못한 채 “이상하다”로 끝내는 경우입니다. 모순은 반드시 구체적으로 지적해야 합니다. “두 정수가 서로소인데 둘 다 짝수다”처럼요.

가정소수가 p₁, p₂, …, pₖ로 유한개뿐이라고 하자.
전개N = p₁ × p₂ × … × pₖ + 1을 생각한다. N을 어느 pᵢ로 나누어도 나머지가 1이다.

결론“소수가 유한개”라는 가정이 틀렸으므로 소수는 무한히 많다.

예제 1 · 대표 문제
칠판에 1부터 10까지 적혀 있다. 두 수 a, b를 지우고 |a − b|를 적는 조작을 한 수만 남을 때까지 반복한다. 남은 수는 홀수인가 짝수인가?
풀이

① 불변량 정하기. 칠판에 적힌 모든 수의 합의 홀짝을 본다.

② 조작 한 번의 변화. a, b가 사라지고 |a − b|가 생기므로 합은 다음만큼 줄어든다.

(a + b) − |a − b| = 2 × min(a, b)

예ab합의 변화짝수인가
①7310 − 4 = 6 감소○
②5510 − 0 = 10 감소○
③9211 − 7 = 4 감소○

어떤 a, b를 골라도 합은 짝수만큼 줄어들므로 합의 홀짝은 변하지 않는다.

③ 시작값. 1 + 2 + … + 10 = 55로 홀수다.

④ 결론. 마지막에 한 수만 남으면 그 수가 곧 전체 합이다. 홀짝이 보존되었으므로 남는 수는 홀수다.

더 알 수 있는 것
남는 수는 0 이상이고 가장 큰 수 10을 넘을 수 없으므로 1, 3, 5, 7, 9 중 하나입니다. 실제로 조작 순서를 잘 고르면 이 다섯 값을 모두 만들 수 있습니다. 불변량은 답을 하나로 정해 주지는 않지만 범위를 크게 좁혀 줍니다.
예제 2 · 색칠 논법
8 × 8 체스판에서 서로 대각선 방향의 두 모서리 칸을 잘라 냈다. 남은 62칸을 1 × 2 도미노 31개로 빈틈없이 덮을 수 있는가?
풀이

① 색칠. 체스판처럼 흰색과 검은색을 번갈아 칠한다. 8 × 8에는 각 색이 32칸씩 있다.

② 불변량. 도미노 하나는 이웃한 두 칸을 덮는데, 이웃한 칸은 항상 색이 다르다. 따라서 도미노 하나는 흰 1칸 + 검은 1칸을 덮는다. 도미노를 몇 개 놓든 덮인 흰 칸 수와 검은 칸 수가 항상 같다.

③ 개수 비교. 대각선 방향의 두 모서리는 색이 같다(예: 둘 다 흰색). 잘라 내면 흰 30칸, 검은 32칸이 남는다.

④ 결론. 도미노 31개는 흰 31칸과 검은 31칸을 덮어야 하는데 흰 칸이 30칸뿐이다. 따라서 덮을 수 없다.

3. “모른다” → 그 사람이 알 수 있었을 경우를 지운다

걸러 내는 규칙
어떤 사람이 “모르겠다”고 했다면, 그 사람이 볼 수 있는 정보가 같은 세계들 중에 자기 모자 색이 두 가지 이상인 세계만 남습니다. 자기 색이 하나로 정해지는 세계는 “알았을 것”이므로 지웁니다.

C의 “모르겠다”를 적용해 봅니다. C는 A와 B를 봅니다.

C가 보는 (A, B)가능한 C의 색C는 아는가
(W, W)흰 모자를 다 썼으므로 C는 R뿐안다 → 이 세계는 지워진다
(R, W), (W, R), (R, R)R도 W도 가능모른다 → 남는다

따라서 ⑦ WWR이 지워지고 6가지가 남습니다.

주의
지우는 것은 “그 사람이 알 수 있었을 세계”입니다. 그 사람의 실제 색이 무엇인지와는 다른 이야기입니다.

4. 대답의 연쇄 — 뒷사람은 앞의 대답을 모두 쓴다

B는 A만 봅니다. 그런데 C의 대답도 들었으므로 남은 6가지 안에서 추론합니다.

B가 보는 A남은 세계에서 B의 색B는 아는가
A = WWRR, WRW에서 B는 항상 R안다 → 이 세계들은 지워진다
A = RRRR, RRW에서 B = R / RWR, RWW에서 B = W모른다 → 남는다

A = W인 세계에서는 C의 대답 덕분에 “A와 B가 둘 다 흰색은 아니다”를 알고 있으므로, A가 흰색이면 B는 반드시 빨강입니다. B가 모른다고 했으므로 A = W인 세계 ⑤ WRR, ⑥ WRW가 지워집니다.

남은 세계는 RRR, RRW, RWR, RWW의 4가지이고 모두 A = R입니다. 따라서 A는 자기 모자가 빨강임을 압니다.

핵심 구조
C의 대답 → 세계가 줄어듦 → B가 그 줄어든 세계에서 추론 → B의 대답 → 다시 줄어듦 → A가 결론. 정보가 앞으로 전달되는 사슬입니다.

5. 순서가 바뀌면 결론도 바뀐다

만약 B가 먼저 말하고 C가 나중에 말했다면 어떻게 될까요? B는 A만 보므로 혼자서는 자기 색을 알 수 없습니다(A가 무엇이든 B는 R도 W도 가능). 따라서 B의 “모르겠다”는 아무 정보도 주지 못하고, 이후 C가 말해도 A는 결론을 내릴 수 없습니다.

순서C → B → AB → C → A
C의 대답세계 7 → 6으로 줄임이미 B가 말했지만 정보 없음. 7 → 6
B의 대답6 → 4로 줄임 (A = R 확정)정보 없음 (A만 보고는 알 수 없음)
A의 결론빨강알 수 없음
왜 그런가
많이 보는 사람이 먼저 말해야 정보가 쌓입니다. 뒤에서 보는 사람의 대답이 앞사람의 추론 재료가 되기 때문입니다. 문제를 읽을 때 말하는 순서를 반드시 확인하세요.

가와 나가 연속한 두 자연수를 하나씩 받았다. 각자 자기 수만 보고, 두 수가 연속한다는 사실은 둘 다 안다.

풀이
단계대답알아내는 것

C
#include <stdio.h>

char w[7][4] = {"RRR","RRW","RWR","RWW","WRR","WRW","WWR"};
int alive[7], keep[7];

void show(const char *t) {
    printf("%s:", t);
    for (int i = 0; i < 7; i++) if (alive[i]) printf(" %s", w[i]);
    printf("\n");
}
void unknown(int pos) {          /* pos 자리 사람이 "모른다" */
    for (int i = 0; i < 7; i++) keep[i] = alive[i];
    for (int i = 0; i < 7; i++) {
        int sR = 0, sW = 0;
        if (!alive[i]) continue;
        for (int j = 0; j < 7; j++) {
            int same = keep[j];
            for (int k = 0; k < pos; k++)
                if (w[j][k] != w[i][k]) same = 0;
            if (same) (w[j][pos] == 'R') ? (sR = 1) : (sW = 1);
        }
        if (sR + sW == 1) alive[i] = 0;   /* 알 수 있었다 */
    }
}

int main(void) {
    for (int i = 0; i < 7; i++) alive[i] = 1;
    show("처음");
    unknown(2);  show("C 모른다");
    unknown(1);  show("B 모른다");
    printf("A의 색: R\n");
    return 0;
}

worlds = ["RRR", "RRW", "RWR", "RWW", "WRR", "WRW", "WWR"]

def show(tag, ws):
    print(f"{tag}: " + " ".join(ws))

show("처음", worlds)

# C의 '모른다': A, B가 같은 세계들 중 C의 색이 하나뿐이면 지운다

          if len({y[2] for y in worlds if y[:2] == x[:2]}) > 1]

# B의 '모른다': A가 같은 세계들 중 B의 색이 하나뿐이면 지운다
keep = worlds[:]
worlds = [x for x in worlds
          if len({y[1] for y in keep if y[0] == x[0]}) > 1]

#include <stdio.h>

int nd(int a, int b) { return !(a && b); }        /* NAND */
int mynot(int a)     { return nd(a, a); }          /* 1개 */
int myand(int a, int b) { int t = nd(a, b); return nd(t, t); }   /* 2개 */
int myor(int a, int b)  { return nd(nd(a, a), nd(b, b)); }       /* 3개 */

int main(void) {
    printf("A B | AND and' | OR  or' | XOR\n");
    for (int a = 1; a >= 0; a--)
        for (int b = 1; b >= 0; b--) {
            int s = a ^ b, c = a && b;             /* 반가산기 */
            printf("%d %d |  %d   %d  |  %d   %d  |  %d\n",
                   a, b, a && b, myand(a, b), a || b, myor(a, b), s);
            if ((a && b) != myand(a, b)) printf("AND 불일치\n");
            if ((a || b) != myor(a, b))  printf("OR 불일치\n");
