}
int main(void) {

    printf("고른 구간:");

    int best = 0;                          /* 전수 조사 2^11 */
    for (int m = 0; m < (1 << 11); m++) {
        int last = -1, k = 0, ok = 1;

            if (m >> i & 1) {
                if (iv[i][0] < last) ok = 0;
                else { last = iv[i][1]; k++; }
            }
        if (ok && k > best) best = k;
    }
    printf("전수 조사 %d개\n", best);

대칭 전략이 통하는 조건
① 상대의 수에 대해 언제나 짝이 되는 수가 있어야 한다.
② 그 수를 두면 다시 대칭인 상태가 되어야 한다.

5. 여러 더미의 님 — XOR 합

님의 정리
더미가 여러 개일 때, 각 더미의 개수를 모두 XOR한 값이 0이면 P위치(지금 차례인 사람이 짐), 0이 아니면 N위치다.

XOR는 주제 06에서 배운 비트 연산입니다. 같은 자리에서 1의 개수가 홀수이면 1, 짝수이면 0입니다.

1, 2, 3001, 010, 0110P위치 — 지금 차례인 사람이 진다
3, 4, 5011, 100, 1012N위치 — 이긴다

① 최적해를 가져온다 겹치지 않는 구간을 가장 많이 고른 방법 하나를 O라 하고, 그 구간들을 끝 시각 순으로 o₁, o₂, …, o_k라 하자.

② 그리디의 첫 선택 전체에서 끝 시각이 가장 빠른 구간을 g라 하자. 그리디는 g를 먼저 고른다.

③ 바꿔치기 O에서 o₁을 g로 바꾼 것을 O′이라 하자. O′도 겹치지 않는 구간들의 모임임을 보인다.

  • g는 전체에서 끝 시각이 가장 빠르므로 (g의 끝) ≤ (o₁의 끝)이다.
  • o₂, o₃, …는 원래 o₁과 겹치지 않았으므로 모두 o₁의 끝 이후에 시작한다.
  • g의 끝이 o₁의 끝보다 앞서거나 같으므로, o₂ 이후의 구간들은 g와도 겹치지 않는다.

따라서 O′ = {g, o₂, o₃, …, o_k}도 서로 겹치지 않고 개수는 여전히 k개다. 곧 바꿔도 손해가 없다.

④ 결론 g를 포함하는 최적해가 존재하므로, 그리디가 g를 고르는 것은 안전하다. g를 고른 뒤 남은 문제는 “g의 끝 이후에 시작하는 구간들에 대한 같은 문제”이므로 같은 논리를 되풀이할 수 있다. 따라서 그리디가 만든 답은 최적이다.

어떤 규칙에 따라 상태가 s₀ → s₁ → s₂ → … 로 바뀐다고 하자. 이 규칙이 다음 상태는 현재 상태로만 정해진다는 성질을 갖는다고 하자. 곧 다음 상태를 f(현재 상태)로 쓸 수 있다.

① 반복이 일어난다 상태의 가짓수가 유한하고 단계는 무한히 이어지므로, 비둘기집 원리에 의해 같은 상태가 두 번 나타나는 시점이 반드시 있다(주제 34). 그 두 시점을 i < j, 곧 sᵢ = sⱼ라 하자.

② 그 뒤가 똑같아진다 다음 상태는 현재 상태로만 정해지므로

si+1 = f(sᵢ) = f(sⱼ) = sj+1

이고, 같은 논리를 되풀이하면 si+2 = sj+2, si+3 = sj+3, … 이 성립한다.

곧 모든 t ≥ 0에 대해 si+t = sj+t다. i 이후의 흐름과 j 이후의 흐름이 완전히 같다.

③ 주기의 뜻 p = j − i라 하면 i 이후의 모든 시점에서 sm = sm+p가 성립한다. p를 주기, i를 꼬리 길이라고 한다. i보다 앞의 상태들은 되풀이되지 않고 한 번만 지나가므로 꼬리에 속한다.

④ 건너뛰기 N이 아주 큰 수일 때 s_N을 구하려면 다음과 같이 한다.

  • N < i이면 꼬리 안이므로 표에서 그대로 읽는다.
  • N ≥ i이면 i + (N − i) mod p 번째 상태가 s_N과 같다.

예를 들어 꼬리가 없고(i = 0) 주기가 4일 때 2026번 뒤의 값은 2026 mod 4 = 2이므로 2단계의 값과 같다. 2026번을 실제로 돌리지 않고 4단계까지만 계산하면 된다.

왜 “현재 상태로만”이 중요한가 만약 다음 상태가 지금까지의 역사에도 달려 있다면, 같은 상태가 다시 나와도 그 뒤의 흐름이 달라질 수 있어 ②가 성립하지 않는다. 그때는 “상태”를 더 크게 잡아 필요한 정보를 모두 담아야 한다.

② 반드시 끝난다 한 바퀴마다 돌이 정확히 4개씩 줄어들고 개수는 0 아래로 내려갈 수 없다. 따라서 유한한 횟수 안에 반드시 0개에 도달한다(주제 26의 단조량).

③ 마지막 돌은 내가 가져간다 ①의 전략을 계속 쓰면 돌이 4m → 4(m−1) → … → 4 → 0으로 줄어든다. 0이 되는 순간은 내가 가져간 직후다. 매 바퀴가 “상대 → 나”의 순서이고 바퀴가 끝날 때마다 4의 배수가 되기 때문이다.

곧 마지막 돌을 가져가는 사람은 나이고, 규칙에 따라 내가 이긴다.

④ 첫수 정하기 처음 돌이 n개일 때 n을 4로 나눈 나머지를 r이라 하자.

  • r ≠ 0이면 r개를 가져가 4의 배수를 남긴다 → 위의 전략으로 이긴다.
  • r = 0이면 내가 무엇을 가져가도 4의 배수가 아닌 수를 남기게 되어, 상대가 같은 전략을 쓸 수 있다 → 내가 진다.

n = 21이면 21 = 4 × 5 + 1이므로 1개를 가져가 20을 남기면 된다.

채점 기준 상대가 x개를 가져가면 4 − x개를 가져간다는 전략(1점), 4 − x가 언제나 1~3 안에 있음을 확인(1점), 한 바퀴에 4개씩 줄어 다시 4의 배수가 됨(1점), 반드시 0에 도달해 끝남(1점), 마지막을 내가 가져감을 결론(1점), 첫수를 나머지로 정함(1점).
