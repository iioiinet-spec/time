#include <stdio.h>
#include <string.h>
int dist[4][6];                  /* 상태 (x, y) */
int qx[64], qy[64], head, tail;

void push(int x, int y, int d) {
    if (dist[x][y] >= 0) return; /* 넣을 때 방문 표시 */
    dist[x][y] = d;
    qx[tail] = x; qy[tail++] = y;
}
int main(void) {
    memset(dist, -1, sizeof dist);
    push(0, 0, 0);
    while (head < tail) {
        int x = qx[head], y = qy[head++], d = dist[x][y];
        if (y == 4 || x == 4) { printf("4L 최소 %d번\n", d); break; }
        int t1 = x < 5 - y ? x : 5 - y, t2 = y < 3 - x ? y : 3 - x;
        push(3, y, d + 1);  push(x, 5, d + 1);     /* 채우기 */
        push(0, y, d + 1);  push(x, 0, d + 1);     /* 비우기 */
        push(x - t1, y + t1, d + 1);               /* 작은 -> 큰 */
        push(x + t2, y - t2, d + 1);               /* 큰 -> 작은 */
    }
    printf("거리 표 (행 x=0..3, 열 y=0..5)\n");
    for (int x = 0; x < 4; x++) {
        for (int y = 0; y < 6; y++) printf("%3d", dist[x][y]);
        printf("\n");
    }
    return 0;
}

dist = {(0, 0): 0}
q = deque([(0, 0)])
while q:
    x, y = q.popleft()

출발점 s에서 BFS를 한다고 하자. 어떤 정점 v에 처음 도달했을 때 적은 거리를 d(v)라 하고, 이것이 실제 최단 거리와 같음을 보인다.

① 큐의 거리는 두 종류뿐이다 BFS를 진행하는 어느 시점에서도 큐에 들어 있는 정점들의 거리는 k 또는 k + 1 두 값뿐이다.

  • 처음에는 s 하나뿐이므로 거리 0만 있다.
  • 거리가 k인 정점을 꺼내면 그 이웃에 k + 1을 적어 넣는다. 곧 k보다 작은 값이 새로 들어가는 일은 없다.
  • 거리 k인 정점을 모두 꺼내고 나면 큐에는 k + 1인 것만 남는다.

따라서 큐에서 정점을 꺼내는 순서는 거리가 작은 것부터이고, 거리가 뒤섞이지 않는다.

② 처음 적은 값이 최단이다 v에 처음 도달했을 때 d(v) = k + 1이었다고 하자. 이때 v는 거리 k인 어떤 정점 u의 이웃이다.

만약 v까지 k + 1보다 짧은 길, 곧 길이가 k 이하인 경로가 있다고 가정하자. 그 경로에서 v 바로 앞 정점을 w라 하면 w까지의 거리는 k − 1 이하다. ①에 의해 거리가 k − 1 이하인 정점은 u보다 먼저 큐에서 꺼내진다. 그러면 그때 이미 v에 거리 k 이하가 적혔을 것이므로, v에 처음 적은 값이 k + 1이라는 사실과 모순이다.

따라서 v까지 k + 1보다 짧은 경로는 없고, 처음 도달했을 때의 거리가 곧 최단 거리다.

왜 다시 적으면 안 되는가 나중에 다른 길로 v에 도달하면 그 거리는 반드시 k + 1 이상이다. 최단값이 이미 적혀 있으므로 덮어쓸 이유가 없다. 이것이 “아직 모를 때만 적는다”는 규칙의 근거다.

채점 기준 큐의 거리가 k, k + 1 두 종류임을 밝힘(2점), 꺼내는 순서가 거리순임을 결론(1점), 더 짧은 경로가 있다고 가정해 모순을 이끎(2점), 덮어쓰지 않는 이유(1점).

다익스트라에서 어떤 정점 u를 확정했다고 하자. 확정할 때 적혀 있던 거리 d(u)가 최종 최단 거리임을, 곧 더 짧은 경로가 없음을 보인다.

① 확정의 규칙 u는 미확정 정점 중 거리가 가장 작은 정점이다. 곧 아직 확정되지 않은 어떤 정점 v에 대해서도 d(u) ≤ d(v)다.

② 귀류법으로 가정 u까지 d(u)보다 짧은 경로 P가 있다고 하자. P는 출발점 s에서 시작해 u에서 끝난다.

③ 첫 미확정 정점을 찾는다 P를 따라가면 처음에는 확정된 정점들을 지나다가 언젠가 미확정 정점을 처음 만난다. 그 정점을 x라 하자. (u 자신이 x일 수도 있다.)

x 바로 앞 정점은 확정되어 있으므로, 그 정점을 확정할 때 이미 갱신이 이루어져 d(x)는 P를 따라 x까지 온 거리 이하다.

④ 모순 P 전체의 길이는 “s에서 x까지의 부분” + “x에서 u까지의 부분”이다. 간선 길이가 모두 0 이상이므로 뒤의 부분은 0 이상이다. 따라서

(P의 길이) ≥ (s에서 x까지의 길이) ≥ d(x)

그런데 ①에 의해 d(u) ≤ d(x)이므로 d(u) ≤ (P의 길이)가 된다. 이는 “P가 d(u)보다 짧다”는 가정과 모순이다.

크루스칼은 간선을 가중치가 작은 순서로 보며, 사이클이 생기지 않으면 고르고 생기면 건너뛴다. 이 방법이 최소 신장 트리를 만든다는 것을 보인다.

① 건너뛰는 간선은 그 사이클에서 가장 비싸다 어떤 간선 e = (u, v)를 볼 때 사이클이 생긴다는 것은, 이미 고른 간선들만으로 u와 v가 이어져 있다는 뜻이다.

그 연결 경로를 P라 하면 P의 간선들은 모두 e보다 먼저 선택되었다. 크루스칼은 가중치가 작은 순서로 보므로 P의 모든 간선은 e보다 가중치가 작거나 같다.

P와 e를 합치면 사이클이 되고, 그 사이클에서 e가 가장 비싼 간선이다.

② 사이클 속성을 적용 사이클에서 가장 비싼 간선은 어떤 MST에도 들어가지 않는다. 그 이유는 다음과 같다.

  • e가 어떤 MST T에 들어 있다고 하자. T에서 e를 빼면 트리가 두 덩어리로 갈라진다.
  • 사이클의 나머지 간선들 중에는 두 덩어리를 다시 잇는 간선 f가 반드시 있다. (사이클을 따라가면 양쪽을 오가기 때문이다.)
  • f는 e보다 싸므로 e 대신 f를 넣으면 다시 신장 트리가 되고 비용은 줄어든다. T가 최소였다는 것에 모순이다.

따라서 건너뛴 간선은 버려도 손해가 없다.

③ 고른 간선은 안전하다 반대로 크루스칼이 고르는 간선은 “지금까지의 덩어리와 바깥을 잇는 간선 중 가장 싼 것”이다. 두 덩어리를 잇는 간선 중 가장 싼 것은 어떤 MST에 반드시 포함될 수 있다(컷 속성). 따라서 고른 간선들만으로 이루어진 것도 언제나 어떤 MST의 일부다.
