1정답 n = 16, 값 289 = 17²
식에 17이 들어 있으므로 17로 묶이는 n을 노린다. n = 16이면
16² + 16 + 17 = 16 × (16 + 1) + 17 = 16 × 17 + 17 = 17 × 17 = 289
n = 1부터 15까지는 19, 23, 29, 37, 47, 59, 73, 89, 107, 127, 149, 173, 199, 227, 257로 모두 소수이므로 가장 작은 반례는 16이다.
자주 하는 오답 n = 17을 답하는 경우. 17² + 17 + 17 = 17 × 19도 합성수지만 16이 더 작다. n + 1 = 17이 되는 자리가 먼저 온다.
2정답 n = 3, 값 9
2¹ + 1 = 3, 2² + 1 = 5는 소수이지만 2³ + 1 = 9 = 3 × 3으로 합성수다.
자주 하는 오답 n = 5(33)를 답하는 경우. n = 3에서 이미 깨진다. 참고로 n이 홀수이면 2ⁿ + 1은 항상 3의 배수다.
3정답 ①, ③, ④
① 거짓. 반례 2.
② 참. 연속한 세 수에는 2의 배수와 3의 배수가 반드시 들어 있다.
③ 거짓. 반례 n = 4: 4! + 1 = 25 = 5².
④ 거짓. 반례 k = 4: 25 = 5².
⑤ 참. (2m+1)(2n+1) = 2(2mn + m + n) + 1로 홀수다.
자주 하는 오답 ③에서 1! + 1 = 2, 2! + 1 = 3, 3! + 1 = 7이 모두 소수라 참으로 넘기는 경우. 몇 개가 맞는 것은 증명이 아니다.

4정답 (1) 1523, 1447, 1373 모두 소수　(2) n = 80
(1) n = 1이면 1 − 79 + 1601 = 1523, n = 2이면 4 − 158 + 1601 = 1447, n = 3이면 9 − 237 + 1601 = 1373이고 모두 소수다. (실제로 n = 1부터 79까지 모두 소수라서 매우 속기 쉽다.)
(2) n = 80을 넣으면
80² − 79 × 80 + 1601 = 80 × (80 − 79) + 1601 = 80 + 1601 = 1681 = 41²
따라서 소수가 아니다. 반례가 하나 있으므로 “어떤 n에 대해 소수가 아니다”는 참이다.
노리는 법 n² − 79n = n(n − 79)이므로 n = 80에서 이 부분이 80이 되어 1601과 더해 1681 = 41²이 된다.
자주 하는 오답 (2)에서 작은 n부터 하나씩 넣어 보다 포기하는 경우. 79개가 모두 소수이므로 식의 구조를 보고 겨냥해야 한다.
채점 기준 (1) 세 값과 판정 2점. (2) 반례 n = 80과 계산 3점, “어떤 n”이므로 반례 하나로 참이 된다는 결론 1점.
5정답 증명
① 보조 사실. “n²이 3의 배수이면 n도 3의 배수이다”를 대우로 보인다.
대우: n이 3의 배수가 아니면 n²도 3의 배수가 아니다.
nn²3으로 나눈 나머지
3k + 19k² + 6k + 1 = 3(3k² + 2k) + 11
3k + 29k² + 12k + 4 = 3(3k² + 4k + 1) + 11
두 경우 모두 나머지가 1이므로 n²은 3의 배수가 아니다. 대우가 참이므로 보조 사실도 참이다.
② 본 증명 (귀류법). √3이 유리수라고 가정하자. 그러면 √3 = a⁄b(a, b는 자연수, 기약분수)로 쓸 수 있다.
양변을 제곱하면 3 = a²⁄b², 곧 a² = 3b²이다.
a²이 3의 배수이므로 ①에 의해 a도 3의 배수다. a = 3m으로 두면 9m² = 3b², 곧 b² = 3m²이다.
b²도 3의 배수이므로 ①에 의해 b도 3의 배수다.
③ 모순. a와 b가 둘 다 3의 배수이므로 3으로 약분된다. 기약분수라는 가정에 어긋난다.
④ 결론. 따라서 √3은 유리수가 아니다.
자주 하는 오답 ①을 빠뜨리고 “a²이 3의 배수니까 a도 3의 배수”라고 그냥 쓰는 경우. 2의 배수와 달리 근거가 필요한 부분이다. 또 기약분수 조건을 처음에 밝히지 않으면 모순을 만들 수 없다.
채점 기준 ① 대우로 보조 사실을 증명 3점. ② 기약분수 가정과 a² = 3b² 유도 2점. ③ a, b가 모두 3의 배수임을 보이고 모순 지적 2점.

6정답 홀수
조작으로 합이 (a + b) − |a − b| = 2 × min(a, b)만큼 줄어드는데 이는 짝수이므로 합의 홀짝은 변하지 않는다.

자주 하는 오답 수의 개수 30이 짝수라서 결과도 짝수라고 답하는 경우. 불변량은 개수가 아니라 합의 홀짝이다.

7정답 불가능
거꾸로 놓인 컵의 수는 한 번에 2 늘거나 2 줄거나 그대로이므로 홀짝이 보존된다. 시작은 0개(짝수), 목표는 7개(홀수)로 홀짝이 다르므로 불가능하다.
자주 하는 오답 “여러 번 해 보니 안 되더라”로 끝내는 경우. 홀짝이 모든 방법을 한꺼번에 막는 이유다.
8정답 가능, 최소 3번
3개씩 뒤집으면 거꾸로 놓인 컵의 수가 홀수만큼 변하므로 홀짝이 매번 바뀐다. 0(짝수)에서 7(홀수)로 가려면 조작 횟수가 홀수여야 한다.
한 번에 3개씩 뒤집으므로 k번이면 뒤집은 횟수의 합이 3k다. 컵 7개가 모두 홀수 번 뒤집혀야 하므로 3k ≥ 7, 곧 k ≥ 3이다. k = 3은 홀수이므로 홀짝 조건도 만족한다.
실제로 3번이면 된다. (1,2,3) → (1,4,5) → (1,6,7)을 뒤집으면 1번 컵은 3번, 나머지 여섯 컵은 1번씩 뒤집혀 모두 홀수 번이 된다. 따라서 일곱 컵이 모두 거꾸로가 된다.
자주 하는 오답 홀짝만 보고 끝내거나, 컵마다 정확히 한 번씩만 뒤집어야 한다고 생각해 불가능하다고 답하는 경우. 같은 컵을 여러 번 뒤집어도 되고, 홀수 번이면 거꾸로가 된다.

10정답 (1) 10번　(2) 11번 불가능, 12번 가능　(3) k ≥ 10이고 k가 짝수
(1) [1,2,3,4,5]의 역순쌍은 0개, [5,4,3,2,1]은 5C2 = 10개다. 인접 교환 한 번이 역순쌍을 정확히 1 바꾸므로 최소 10번이다.
(2) 교환할 때마다 역순쌍이 1 늘거나 1 줄므로 홀짝이 매번 바뀐다. 0에서 10(짝수)으로 가려면 교환 횟수도 짝수여야 한다. 따라서 11번(홀수)은 불가능하고 12번은 가능하다. 10번 만에 만든 뒤 아무 이웃이나 두 번 왕복하면 12번이 된다.
(3) k ≥ 10이고 k와 10의 홀짝이 같아야 하므로 k는 10 이상의 짝수다.
자주 하는 오답 (2)에서 “11번은 10번보다 많으니 가능하다”고 답하는 경우. 횟수가 많다고 되는 것이 아니라 홀짝이 맞아야 한다.
채점 기준 (1) 역순쌍으로 최소 횟수를 구함 3점. (2) 홀짝이 매번 바뀜을 설명하고 두 경우 판정 3점. (3) 1점.

11정답 A와 B 모두 흰색
C가 알 수 있는 경우는 A와 B가 둘 다 흰색일 때뿐이다. 흰 모자는 2개뿐이므로 앞의 두 사람이 다 쓰면 C는 반드시 빨강이기 때문이다. 다른 경우에는 C의 색이 빨강일 수도 흰색일 수도 있어 알 수 없다.

12정답 흰색
C의 “모른다”로 A와 B가 둘 다 흰색인 경우가 지워진다. 곧 “A와 B가 둘 다 흰색은 아니다”를 모두가 알게 된다.
B는 A를 본다. A = W라면 B 자신은 흰색일 수 없으므로(둘 다 흰색이 되어 C가 알았을 것) 자기가 빨강임을 확정할 수 있다. A = R이라면 B는 빨강도 흰색도 가능해 알 수 없다.
B가 안다고 했으므로 A는 흰색이다.
자주 하는 오답 B가 안다고 했으니 B의 색을 답하는 경우. 문제는 A의 색을 묻는다. (참고로 이때 B는 빨강이다.)
