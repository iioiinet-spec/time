2. 합·차·곱은 나머지끼리 계산해도 된다

정리 · 합동식의 연산
a ≡ b (mod m)이고 c ≡ d (mod m)이면
a + c ≡ b + d,　a − c ≡ b − d,　a × c ≡ b × d (mod m)
따라서 ak ≡ bk (mod m)도 성립합니다.

예를 들어 123 × 456을 7로 나눈 나머지를 구할 때 곱셈을 하지 않아도 됩니다.

5. 음수의 나머지와 C의 % 연산

#include <stdio.h>

/* (a^n) % m 을 곱할 때마다 나머지를 취하며 계산 */
long powmod(long a, long n, long m) {
    long r = 1;
    a %= m;
    for (long i = 0; i < n; i++)
        r = (r * a) % m;          /* 매번 나머지 */
    return r;
}

int main(void) {
    printf("7^2026 mod 10  = %ld\n", powmod(7, 2026, 10));
    printf("7^2026 mod 100 = %ld\n", powmod(7, 2026, 100));

def powmod(a, n, m):              # (a^n) % m
    r = 1
    a %= m
    for _ in range(n):
        r = (r * a) % m           # 매번 나머지
    return r

②개념과 정리

1. 호제법의 원리

정리
b > 0일 때 gcd(a, b) = gcd(b, a mod b)

이유는 공약수의 모임이 그대로 유지되기 때문입니다. a = bq + r이라 할 때

방향설명
a, b의 공약수 → b, r의 공약수d가 a와 b를 모두 나누면 r = a − bq도 나눈다
b, r의 공약수 → a, b의 공약수d가 b와 r을 모두 나누면 a = bq + r도 나눈다

두 쌍의 공약수 모임이 완전히 같으므로 가장 큰 공약수도 같습니다. 서술 문제에서 이것을 자세히 씁니다.

왜 빨라지는가
나머지 r은 반드시 b보다 작습니다. 곧 다루는 수가 매번 줄어들므로 반드시 끝납니다(주제 26의 단조량). 게다가 두 단계마다 수가 절반 이하로 줄어 아주 빠릅니다.

2. 나눗셈 단계 수

단계 수는 두 수의 크기보다 비율에 달려 있습니다. 가장 오래 걸리는 것은 연속한 피보나치 수일 때입니다.

a, b(5, 3)(8, 5)(13, 8)(21, 13)(34, 21)(55, 34)
단계 수345678

피보나치 수열(주제 15)이 여기서 다시 나타납니다. 각 단계의 몫이 모두 1이어서 가장 느리게 줄어들기 때문입니다.

자주 하는 실수
“나머지가 0이 된 단계”까지 세는지 아닌지 헷갈리는 경우입니다. 이 교재에서는 나눗셈을 실제로 한 횟수를 셉니다. 1071과 1029는 나눗셈 3번, 마지막 나눗셈에서 나머지 0이 나옵니다.

3. ax + by로 만들 수 있는 수

정리
정수 x, y를 마음대로 고를 때 ax + by로 만들 수 있는 수는 정확히 gcd(a, b)의 배수 전부입니다.

예를 들어 a = 6, b = 10이면 gcd = 2이므로 6x + 10y로 만들 수 있는 양수는 2, 4, 6, 8, …인 짝수 전부입니다.

목표가능한가예 또는 이유
6x + 10y = 2가능x = 2, y = −1
6x + 10y = 14가능x = 4, y = −1
6x + 10y = 7불가능7은 2의 배수가 아니다
정수해 존재 조건
ax + by = c에 정수해가 있을 조건은 c가 gcd(a, b)의 배수인 것입니다.

왼쪽의 ax + by는 언제나 gcd(a, b)로 나누어떨어지므로, 오른쪽 c가 그 배수가 아니면 해가 있을 수 없습니다.

a를 b로 나눈 몫을 q, 나머지를 r이라 하자. 곧 a = bq + r이고 r = a − bq다.

“a와 b의 공약수 전체”를 모임 S, “b와 r의 공약수 전체”를 모임 T라 하고 S = T임을 두 방향으로 보인다.

① S에 속하면 T에도 속한다. d가 a와 b를 모두 나눈다고 하자. a = d·s, b = d·t로 쓰면

r = a − bq = d·s − d·t·q = d(s − tq)

괄호 안이 정수이므로 d는 r도 나눈다. d는 b도 나누므로 d는 b와 r의 공약수, 곧 T에 속한다.

② T에 속하면 S에도 속한다. d가 b와 r을 모두 나눈다고 하자. b = d·u, r = d·v로 쓰면

a = bq + r = d·u·q + d·v = d(uq + v)

괄호 안이 정수이므로 d는 a도 나눈다. d는 b도 나누므로 d는 S에 속한다.

결론 ①과 ②에 의해 S와 T는 완전히 같은 모임이다. 같은 모임이므로 그 안에서 가장 큰 원소도 같고, 따라서

gcd(a, b) = gcd(b, r) = gcd(b, a mod b)

왜 끝나는가 r은 항상 b보다 작으므로 다루는 수가 매번 줄어든다. 0 아래로는 내려갈 수 없으므로 유한한 단계 안에 나머지가 0이 되고, 그때의 값이 최대공약수다.

따라서 0번으로 처음 돌아오는 것은 j = n′ = n ÷ d일 때이고, 그때까지 j = 0, 1, …, n′ − 1의 n′개 점을 방문한다.

결론 방문하는 점의 수는 n ÷ gcd(n, k)이다.
